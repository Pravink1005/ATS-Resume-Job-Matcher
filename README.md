# ResumeMatch ATS

Explainable resume-to-job matching for evaluating how well a resume fits a job description. ResumeMatch ATS combines conservative evidence matching with structured scoring for skills, experience, education, competencies, keywords, and text similarity.

## Features

- Upload one PDF, DOCX, or TXT resume with magic-byte header validation
- Dual Job Source: paste custom text manually **OR** select live roles from connected Supabase database (5,000+ real job descriptions)
- FastAPI backend with interactive Swagger documentation
- Streamlit interface with 4-tab evaluation (Overview, Requirements, Evidence, ATS Notes) and Match History viewer
- Exact, alias, partial, and related skill matching
- Structured job requirement extraction
- Experience gap and education relevance analysis
- Context matching: Title overlap, Seniority level, Location compatibility, and Work authorization
- Explainable requirement-level evidence and recommendations
- TF-IDF text similarity as a supporting signal
- SQLite persistence with complete requirement and context restoration
- Downloadable formatted `.docx` ATS report
- Docker and Docker Compose support

## How Scoring Works

The matcher favors explicit resume evidence. A related technology does not automatically satisfy a requirement, and broad keyword overlap does not inflate the result.

Requirements are categorized as technical skills, experience, education, competencies, or responsibilities. Each category contributes to the final ATS score through a weighted breakdown. Preferred requirements are reported separately, while missing required evidence remains visible.

For example, `2+ years preferred` is not treated as an automatic rejection. The result shows the candidate's experience, the required experience, and the remaining gap.

## Quick Start

### Windows PowerShell

```powershell
git clone <your-repository-url>
cd ATS-Resume-Job-Matcher
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.database.init_db
pytest -v
```

Start the API:

```powershell
uvicorn app.main:app --reload
```

In a second PowerShell window, activate the environment and start the frontend:

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run frontend\app.py
```

Open the application at [http://127.0.0.1:8501](http://127.0.0.1:8501). API documentation is available at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

### Docker Compose

```powershell
docker compose up --build
```

## API Overview

The backend provides routes for health checks, resume and job management, stored matches, and direct file matching.

The simplest workflow is:

1. Upload or create a resume.
2. Create a job description.
3. Request a match using the resume and job IDs.

For the one-step frontend workflow, use `POST /match/file` with a resume file and a `job_description` form field. The response includes the overall score, recommendation, component scores, matched and missing skills, experience details, and explanations.

Interactive API documentation is generated by FastAPI at `/docs`.
